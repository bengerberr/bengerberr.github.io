# bengerberr.github.io

Home screen pages for Ben's Apps Script web apps. iPhones take the icon and name from the page you're on when you tap Add to Home Screen, and Apps Script pages belong to Google, so each app gets a small page here that shows it full screen with a proper icon.

| Page | App |
|---|---|
| [/](https://bengerberr.github.io/) | Gerber's Games: home screen hub that opens all the other apps |
| [/amber-games/](https://bengerberr.github.io/amber-games/) | Amber Games: Mastermind and Words |
| [/bobble-ball/](https://bengerberr.github.io/bobble-ball/) | Bobble Ball: scores, stats, seasons and the Book of Bobble |
| [/emperor-scum/](https://bengerberr.github.io/emperor-scum/) | Card Club: Emperor Scum and Golf |
| [/gerber-pay/](https://bengerberr.github.io/gerber-pay/) | Gerber Pay (private: the app link is never stored here) |
| [/six-at-six/](https://bengerberr.github.io/six-at-six/) | 6 at 6: six morning habits, progress photos and stop motion |
| [/stagescript/](https://bengerberr.github.io/stagescript/) | Stagescript prompt book |

The source for each page lives with its app in the private `apps` repo (`<app>/home/`) and is copied here.
