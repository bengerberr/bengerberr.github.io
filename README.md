# bengerberr.github.io

Home screen pages for Ben's Apps Script web apps. iPhones take the icon and name from the page you're on when you tap Add to Home Screen, and Apps Script pages belong to Google, so each app gets a small page here that shows it full screen with a proper icon.

| Page | App |
|---|---|
| [/emperor-scum/](https://bengerberr.github.io/emperor-scum/) | Emperor Scum card game |
| [/stagescript/](https://bengerberr.github.io/stagescript/) | Stagescript prompt book |

The source for each page lives with its app in the private `apps` repo (`<app>/home/`) and is copied here.
